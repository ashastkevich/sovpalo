# IT-документация

Техническая документация сайта «Совпало»: архитектура, решения (ADR), устройство кода, инфраструктура, инструкции для разработки и эксплуатации.

| Раздел | Описание |
|---|---|
| [`architecture/`](architecture/README.md) | Архитектурные решения (ADR): стек, устройство сайта |

## Как вносить изменения

Изменения в этой папке **пушим сразу в `main`, без Pull Request**.

Правило действует только для `docs/it/`. Коммит, который затрагивает что-то за пределами этой папки, оформляем через Pull Request, как вся остальная документация (см. [`docs/README.md`](../README.md)).

Правила оформления — общие для `docs/`: Markdown, русский язык, имена файлов латиницей через дефис.
