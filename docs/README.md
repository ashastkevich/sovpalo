# Документация проекта Sovpalo

Здесь хранится вся документация по проекту.

## Структура

| Раздел | Описание |
|---|---|
| [`business-requirements/`](business-requirements/README.md) | Бизнес-требования: цели, пользователи, функциональные и нефункциональные требования, журнал решений |
| [`it/`](it/README.md) | IT-документация: архитектура и ADR, устройство кода, инфраструктура |

Новые разделы (например, `glossary.md`) добавляются по мере необходимости.

## Как вносить изменения

**Исключение — папка [`it/`](it/README.md):** изменения в ней пушим сразу в `main`, без Pull Request. Всё остальное — только через Pull Request:

1. Создайте ветку от `main`, например `docs/br-onboarding`.
2. Внесите изменения в файлы в папке `docs/`.
3. Откройте Pull Request в `main` и кратко опишите, что и зачем изменено.
4. Дождитесь ревью и одобрения от владельца проекта. Прямые коммиты в `main` не делаем.

## Правила оформления

- Формат: Markdown (`.md`).
- Язык: русский.
- Один документ — одна тема. Большие разделы делим на отдельные файлы.
- Имена файлов: латиницей, через дефис, например `user-roles.md`.
- Изображения и схемы кладём в `docs/assets/`.
