# Совпало — векторная версия 2

Надпись восстановлена по скриншоту «Screenshot 2026-10-29 at 16.03.19.png». Возвращены плотные межбуквенные интервалы; сохранены индивидуальные контуры букв, пропорции, скругления, внутренние просветы «в», скошенный внутренний угол «п» и форма «л» без изогнутого левого окончания. Буквы не заменены готовым шрифтом. Контуры сглажены только на субпиксельном уровне, чтобы убрать неровности растрового изображения.

Знак и иконки сохранены из версии 1. Цвет надписи подобран по скриншоту: `#242423`; синий знак — `#0043F0`. Фон и текстура скриншота в логотип не входят. Все рабочие SVG и PNG имеют прозрачный фон, кроме иконок приложения на синем квадрате.

## Файлы

- `logo-color.svg` — основной логотип: синий знак и тёмная надпись.
- `logo-black.svg`, `logo-white.svg` — чёрный и белый варианты.
- `logo-dark.svg` — синий знак и белая надпись для тёмного фона.
- `wordmark.svg` — надпись отдельно; также есть `wordmark-black.svg` и `wordmark-white.svg`.
- `symbol.svg`, `symbol-black.svg`, `symbol-white.svg` — знак отдельно.
- `app-icon.svg` — иконка для 32 px и более.
- `app-icon-small.svg` — оптическая версия для 16–24 px с увеличенным просветом между частями знака.
- `favicon.ico` — иконки 16, 24, 32, 48, 64, 128 и 256 px.
- `png/` — прозрачные PNG логотипа шириной 2400 px, надпись шириной 1800 px и образцы малых размеров.
- `icons/` — PNG знака и иконки 16–512 px.
- `comparison.png` — исходный скриншот и вектор в одинаковом масштабе.
- `preview.png` — полный просмотр с проверкой малых размеров; открывайте при масштабе 100%.
- `logo-preview.png`, `wordmark-preview.png` — крупные просмотры на светлом фоне.

В SVG только редактируемые векторные контуры: без встроенных изображений, шрифтов и внешних зависимостей. Семь букв представлены отдельными составными контурами, их положения зафиксированы по образцу. У двух «о» сохранены индивидуальные очертания.

## Проверка

При сравнении в исходном размере 898 × 176 px пересечение силуэтов растра и вектора составляет 99,66% от их объединения. Сравнение проведено по бинарным маскам на середине перехода между цветом букв и фоном; различия сосредоточены на сглаженных краях. Это показатель точности восстановления силуэта, а не оценка узнаваемости логотипа.

Рекомендуемая минимальная ширина **полного логотипа — 240 px** при отображении 1×. На 240 и 320 px семь букв остаются раздельными, пять закрытых внутренних просветов сохраняются. На 180–200 px некоторые соседние буквы местами соприкасаются при растеризации. Интервалы специально не расширены, чтобы сохранить ваш образец. Для более узких мест используйте отдельный знак.

Для отдельного знака рекомендуется 24 px и более; на 16 px обе части остаются раздельными. Для favicon используйте готовый ICO или `icons/app-16.png`. В пакете есть PNG 1× для сравнения, но в интерфейсе предпочтителен SVG, который адаптируется к плотности экрана.

Не растягивайте логотип отдельно по ширине или высоте. Рекомендуемое свободное поле вокруг — не менее четверти высоты знака; небольшой технический отступ внутри SVG его не заменяет.
