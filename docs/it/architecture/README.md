## Как добавить ADR

1. Скопируйте структуру существующего ADR: контекст, решение, отклонённые варианты, последствия.
2. Номер — следующий по порядку, имя файла — латиницей через дефис.
3. Принятый ADR не переписываем. Если решение меняется, пишем новый ADR и в старом ставим статус «Заменено ADR-NNNN».
